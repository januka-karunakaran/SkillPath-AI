# 🚀 SkillPath AI

SkillPath AI is a full-stack learning platform that helps users discover personalized learning paths based on their goals and skill level.

---

## 🧩 Features

- 🔐 User Authentication (Login / Signup)
- 🎯 Career Path Selection
- 📊 Learning Path Recommendations
- 📚 Course Modules (Beginner → Advanced)
- 📈 Progress Tracking
- 🧠 Smart Learning Flow (Locked / Unlocked courses)

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS

### Backend
- FastAPI (Python)
- MongoDB

### Authentication
- JWT (JSON Web Tokens)
